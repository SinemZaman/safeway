SafeWay

SafeWay ist eine Website über sichere Heimwege für Jugendliche in Österreich.
Sie richtet sich an Jugendliche, die mit Freunden unterwegs sind, Partys besuchen oder abends länger draußen bleiben.
Die Website soll dabei helfen, verschiedene Möglichkeiten zu finden, um sicher nach Hause zu kommen.
Geplant sind Informationen über öffentliche Verkehrsmittel, die nächstgelegenen Haltestellen und ungefähre Taxikosten.
Außerdem werden wichtige Notfallnummern für Österreich übersichtlich dargestellt.
